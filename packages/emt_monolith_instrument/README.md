# EmT Monolith Instrument - GUI Asset Package

A fierce minimalist, sacred-geometry audio instrument plugin GUI.

## Included Assets:
1. `master_gui_1200x600.png` - Full composite 1200x600 instrument interface.
2. `chassis_background_1200x600.png` - Modular blank faceplate in deep volcanic black ash and distressed metal with celestial noise grain.
3. `dial_calibration_ring.png` - Transparent circular astrolabe calibration track with warm dormant amber graduation lines.
4. `dial_cap_monolith.png` - Transparent turned metal rotary knob cap with matte tangerine indicator notch (#C2531A to #E8732A).
5. `button_bypass_active.png` - Low-profile tactile bypass switch.

## Layout Specs:
- Canvas: 1200 x 600 px
- Dials: 4 horizontally spaced rotary controls (Gain, Attack, Release, Mix)
- Color Palette: Deep black ash (#0D0E11), dormant amber (#281A10), matte tangerine (#E8732A).
