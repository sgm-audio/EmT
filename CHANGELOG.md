# Changelog

## [0.1.0] - 2026-05-30

### Added
- Python export pipeline: `export_mamba_weights.py` exports PyTorch MambaBlock → flat-binary weight loader format; `validate_export.py` validates round-trip correctness
- Proper conditioning projection layer (`cond_proj_dt`, `cond_proj_B` weights) replacing crude 0.01/0.001 modulation hack
- Benchmark infrastructure (`benchmark_ssm_block.cpp`) with per-sample and block processing benchmarks for single and multi-layer configurations
- Benchmark target registered in `tests/CMakeLists.txt`

### Fixed
- **Critical**: B double-counting in SSM recurrence (`ssm_block.cpp`). `B_bar` already incorporates the B projection via ZOH discretization `(exp(A*delta)-1)/A * B`, but the state update multiplied by `B_[i]` again, squaring the B projection
- **Critical**: Weight file layout mismatch between test data and `get_layer_pointers()` — `b_in` vs `W_ssm` ordering now consistent
- Blocking I/O in audio thread: `WeightLoader::load()` + per-layer `memcpy` moved out of `plugin_process()` into main-thread `load_weights()`
- Heap allocation in `plugin_init()`: replaced `new SSMInferenceCore` with placement-new into pre-allocated `core_storage[]`
- Python forward pass dimension error in `MambaBlock.forward()`: `F.linear` vs direct `matmul` convention mismatch for B/C projections

### Changed
- `SSMWeights` struct: added `cond_proj_dt[MAX_D_STATE][COND_DIM]` and `cond_proj_B[MAX_D_STATE][COND_DIM]`
- Weight file format v1: extended per-layer layout with conditioning projection weights (appended after `b_in`)
- `WeightLoader::floats_per_layer()` and `get_layer_pointers()`: account for conditioning projection weights
- `SSMInferenceCore`: added default constructor and `init()` method for two-phase placement-new construction
- `config.h`: auto-generated by export pipeline (regenerated at export time)
